# HTML Parsing

## Описание проекта

Проект предназначен для изучения структуры HTML-документов, CSS-селекторов и извлечения данных с помощью JavaScript.

## Структура проекта

- `html/` — исходные HTML-файлы.
- `report.md` — отчёт с CSS-селекторами, тегами и атрибутами.
- `parser.js` — скрипт для извлечения данных из HTML.
- `parsed_data.json` — результат работы парсера.
- `package.json` — настройки проекта и зависимости Node.js.

## Запуск

1. Установить Node.js.
2. Установить зависимости командой `npm install`.
3. Запустить парсер командой `node parser.js`.

## Результат

Скрипт обрабатывает HTML-файлы из папки `html` и сохраняет извлечённые данные в `parsed_data.json`.
